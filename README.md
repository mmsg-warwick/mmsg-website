# Mathematical Modelling for Sustainability Group Website

[![Netlify Status](https://api.netlify.com/api/v1/badges/3c5429b2-8eb3-49d8-9b4f-e8202b90f766/deploy-status)](https://app.netlify.com/projects/mmsg-website/deploys)

Website for the Mathematical Modelling for Sustainability Group (MMSG) at the University of Warwick.

It is a static site built with [Hugo](https://gohugo.io/) and the [Blowfish](https://blowfish.page/) theme, and deployed with [Netlify](https://www.netlify.com/). Every pull request gets a Netlify deploy preview, and merging into `main` publishes the site.

## Common tasks

Most updates only need a Markdown or YAML file to be edited. Step-by-step guides:

| Find which file controls which page          | [docs/content-model.md](docs/content-model.md)               |

See [CONTRIBUTING.md](CONTRIBUTING.md) for how to submit a change.

## Running the site locally

You need:

- [Hugo](https://gohugo.io/installation/), **extended** edition (`hugo version` should print `+extended`). Use the version in [netlify.toml](netlify.toml) (currently 0.163); newer versions may work but print a warning that the theme does not support them yet.
- [Go](https://go.dev/doc/install), which Hugo uses to download the Blowfish theme (a Hugo module, see [go.mod](go.mod)).
- [Git](https://git-scm.com/).

Then:

```bash
git clone https://github.com/mmsg-warwick/mmsg-website.git
cd mmsg-website
hugo server
```

and open <http://localhost:1313/>. The page reloads as you edit files. Use `hugo server -D` to also show pages marked `draft: true`.

The first run downloads the theme, so it needs an internet connection.

### Optional: pre-commit

The repository uses [pre-commit](https://pre-commit.com/) to fix trailing whitespace, line endings and missing final newlines. It also runs automatically on pull requests via pre-commit.ci, so installing it locally is optional:

```bash
pip install pre-commit
pre-commit install
```

## Repository layout

```text
content/        Pages, written in Markdown (one folder per section)
data/           Structured content: publications, software, opportunities
layouts/        Templates that override or extend the Blowfish theme
static/         Files copied as-is to the site (logos, favicons, software logos)
scripts/        update_publications.py (Zotero → data/publications.json)
docs/           Guides for maintaining the site
hugo.toml       Site configuration: title, base URL, theme settings, menu
netlify.toml    Netlify build settings, including the Hugo version
.github/        GitHub Actions workflows and Dependabot configuration
```

`public/` and `resources/` are generated by Hugo and are not committed.

## Automation

| Workflow                                                                    | When                                    | What it does                                                                                                                                                         |
| --------------------------------------------------------------------------- | --------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Update Publications](.github/workflows/update_publications.yaml)           | Mondays 07:00 UTC, or by hand           | Downloads the publications from Zotero and opens a pull request if anything changed. See [docs/adding-publications.md](docs/adding-publications.md).                 |
| [Check Links](.github/workflows/check_links.yaml)                           | Pushes and PRs to `main`, Mondays 08:00 | Builds the site and checks every link with [lychee](https://lychee.cli.rs/). A failure usually means an external link has moved; fix or remove it.                   |
| Netlify                                                                     | Every PR and every push to `main`       | Builds a deploy preview for each PR (linked in the PR checks) and publishes `main` to the live site.                                                                 |
| [Dependabot](.github/dependabot.yaml) and pre-commit.ci                     | Periodically                            | Open PRs to update GitHub Actions and pre-commit hooks. Merge them once the checks pass.                                                                              |

### Updating Hugo or the theme

- **Hugo**: change `HUGO_VERSION` in [netlify.toml](netlify.toml) and `hugo-version` in [check_links.yaml](.github/workflows/check_links.yaml), keeping them the same. Check that the Blowfish version in [go.mod](go.mod) supports it (`hugo mod graph` warns if not).
- **Blowfish**: run `hugo mod get -u github.com/nunocoracao/blowfish/v2` and commit the changes to `go.mod` and `go.sum`. Check the deploy preview carefully, since the templates in `layouts/` override parts of the theme.
